🍳 Tin's Family Cookbook — one-time setup (about 5 minutes)

This turns the cookbook into a shared family website: everyone opens one link, and every edit or new dish is saved for the whole family in your Google Drive. You only do this once.

You need the two files that came with this guide: Code.gs and index.html.

Part 1 — Create the app

1
On your computer, open script.google.com in a browser and sign in with your Google account (solinangai@gmail.com).
2
Click + New project. A code editor opens with a file called Code.gs.
3
Click the name "Untitled project" (top-left) and rename it to Tin's Family Cookbook.
4
Open the provided Code.gs file in Notepad. Select all (Ctrl+A), copy (Ctrl+C). Back in the browser, click inside the code area, select all, and paste — replacing everything that was there.
5
In the left sidebar, next to Files, click ＋ → HTML. Type the name index exactly (lowercase, no ".html") and press Enter.
6
Open the provided index.html in Notepad, select all, copy, and paste it into the new index.html file in the browser — again replacing everything.
7
Press Ctrl+S (or the 💾 icon) to save the project.

Part 2 — Publish it

8
Click the blue Deploy button (top-right) → New deployment.
9
Click the ⚙ gear next to "Select type" and choose Web app. Then set:
• Execute as: Me
• Who has access: Anyone
Click Deploy.
10
Google will ask you to authorise: click Authorize access, pick your account. If it says "Google hasn't verified this app", click Advanced → Go to Tin's Family Cookbook (unsafe) → Allow. This warning is normal — it's your own private app, and the permission only lets it save the recipe file in your own Drive.
11
Copy the Web app URL (it starts with https://script.google.com/macros/s/…). That's the family cookbook link! Send it to the family WhatsApp group.

Part 3 — On each phone

12
Open the link in Safari (iPhone) or Chrome (Android) — not inside the WhatsApp preview. Tap Share → Add to Home Screen. It now opens like an app, full screen, with an icon.

Good to know

🌐 Auto-translation: when anyone adds or edits a dish, they can type English only — empty Chinese boxes are filled in automatically by Google Translate when saving.
☁ Where the data lives: everyone's edits are saved to a file called tins-cookbook-data.json in your Google Drive. Deleting that file resets the cookbook to the original recipes.
🔒 Privacy: anyone who has the link can view and edit, without logging in — so share the link only with family.
🔄 Future updates: if Claude gives you an updated index.html later, paste the new content over the old one, then Deploy → Manage deployments → ✎ (pencil) → Version: New version → Deploy. The family link stays the same.
